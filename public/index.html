        How a class works

        Study Helper is a tutor for the syllabus you upload. Accounts, notes, timetables, and exercise keys are JSON files in your GitHub repository. Passwords are stored as SHA-256 hashes, never as plain text.

        1. Register, then add your name, grade, subjects, exam date, and how many hours you can study.
        2. Upload a PDF or DOCX. Topics are read by Gemini and kept as an outline — the file itself is not stored.
        3. Chat on the tutor desk when you want a hint instead of the whole answer.
        4. Live class asks you to confirm English or Chichewa, then draws the lesson in chalk. Speech plays at rate 0.65 after the writing finishes.
        5. Raise hand uses the microphone (webkitSpeechRecognition when the browser has it). You can always type instead.
        6. Exercises can be typed or handed in as a photo or PDF. Grading stays on the server so the answer key is not sent to the browser.

        Chichewa speech uses a ny-MW voice when the device has one. If it does not, the words are still Chichewa and the device voice does its best.
